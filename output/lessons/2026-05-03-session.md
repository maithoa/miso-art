# Session Lessons Learnt — 2026-05-03

## Pains & How They Were Resolved

- **SQL migration: `storage.policies` table doesn't exist**
  _What happened:_ Agent-generated SQL tried to insert into `storage.policies`, which doesn't exist in Supabase.
  _Resolved by:_ Rewrote the migration to use `CREATE POLICY ... ON storage.objects` instead.

- **UUID format invalid in seed data (`seed` is not hex)**
  _What happened:_ Running `004_seed_extended.sql` failed with `invalid input syntax for type uuid: "a1000001-seed-4004-..."`.
  _Resolved by:_ Replaced the non-hex segment `seed` with valid hex `5eed` across all 20 rows.

- **Checkout page: "Failed to send a request to the Edge Function"**
  _What happened:_ Checkout showed the error immediately on page load. Two sub-problems found:
  (1) Edge Function was called on mount before customer info was collected.
  (2) Cart items were sent as full objects `{ id, name, price }` but Edge Function expects `{ product_id, quantity }`.
  _Resolved by:_ Rewrote `Checkout.jsx` as a two-step form — step 1 collects customer info, step 2 calls the Edge Function with correctly mapped items + customer object, then mounts Stripe PaymentElement with the returned `clientSecret`.

- **Checkout still failing after the fix — "Failed to send a request"**
  _What happened:_ Even with the correct payload, the Edge Function returned `UNAUTHORIZED_INVALID_JWT_FORMAT`. Curl confirmed the function IS deployed but rejects the `sb_publishable_` anon key as a Bearer token.
  _Resolved by:_ ⏳ Still open. Likely fix: get the legacy JWT anon key (`eyJ...`) from Supabase Dashboard → Settings → API and replace `VITE_SUPABASE_ANON_KEY` in `.env`.

- **CartDrawer tests failing: `localStorage.clear is not a function`**
  _What happened:_ jsdom's `localStorage` doesn't implement `.clear()`, so all 12 CartDrawer tests threw `TypeError` in `beforeEach`.
  _Resolved by:_ Added `vi.stubGlobal('localStorage', localStorageMock)` pattern (already established in CartContext tests). Also added `MemoryRouter` wrapper (needed for `useNavigate`) and fixed currency regex to match de-DE format `15,00 €` instead of `$15.00`.

- **Deno + TypeScript errors in Edge Function**
  _What happened:_ VS Code showed `Deno is not defined` and `property 'is_available' does not exist` in `create-payment-intent/index.ts`.
  _Resolved by:_ Added `"deno.enablePaths": ["supabase/functions"]` to `.vscode/settings.json`, added `supabase/functions/deno.json` with strict compiler options, and explicitly typed the `Map<string, ProductRow>` generic so TypeScript resolves `product.is_available` and `product.price` correctly. Requires the Deno VS Code extension to be installed.

- **Agent truncating output mid-JSON (`max_tokens` too low)**
  _What happened:_ Agents produced incomplete JSON that couldn't be parsed, causing sprint runs to fail.
  _Resolved by:_ Increased `max_tokens` from 4096 to 16000 in `agents/worker.js`.

- **Dev 2 files not written when only one issue was forced**
  _What happened:_ `else if (issues[1])` guard in the orchestrator skipped writing Dev 2's output when `toRun` had only one issue.
  _Resolved by:_ Changed to `const dev2Issue = issues[1] ?? issues[0]` so both devs' output is always committed.

- **Agent generating prose instead of JSON (devBackend role)**
  _What happened:_ Dev 2 wrote reasoning/character narration before the JSON output, then ran out of tokens before finishing the JSON.
  _Resolved by:_ Restructured `devBackend` role in `roles.js` — moved character traits to a `CODING PRINCIPLES (apply silently)` section that doesn't appear in output.
